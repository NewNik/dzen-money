# 0001. Google Apps Script + переносимое TS-ядро

Дата: 2026-11-10. Статус: предложено (по результатам исследования), подтвердить после этапа 0.

## Решение
Письма обрабатывает Google Apps Script по таймеру (5–10 мин), запись в Дзен-мани через `/v8/diff/`.
Ядро (парсер, маппер, клиент, UUIDv5) — чистый TypeScript, тесты Vitest, сборка esbuild, деплой clasp.

## Почему
- Бесплатно, без сервера, без OAuth-приложения Google и без продления Gmail watch.
- Токены Google не покидают Google.
- Ядро переносимо в Node-сервис, если Apps Script станет тесен.

## Отвергнуто
- Gmail API + Pub/Sub: инфраструктура без выгоды для одного пользователя.
- IMAP + app password: слишком широкий доступ.
- Свой Zen-плагин: нет почтового API, нужен PR в общий репозиторий.
- n8n/Make: нет узла Дзен-мани, логика diff в Code node.

## Риски
Токен Дзен-мани (срок жизни не подтверждён), недокументированные обязательные поля API.
