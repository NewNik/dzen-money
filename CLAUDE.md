# dzen-money — контекст для Claude Code

Цель: письма Vietcombank из Gmail → операции в Дзен-мани через `POST /v8/diff/`.

## Структура
- `kb/` — база знаний (markdown). Читать `kb/plan.md` первым.
- `app/` — код. `app/src/core` — чистый TS (парсер, маппер, клиент), без Node/GAS API. `app/src/gas` — тонкий слой Apps Script.

## Правила
- Язык документации и комментариев — русский.
- Идемпотентность: id транзакции = UUIDv5 от Order Number. Никогда не отправлять `deletion` в Дзен-мани.
- Дата операции — локальная вьетнамская (UTC+7), формат письма DD/MM/YYYY.
- Не коммитить: сырые .eml, токены, реальные номера счетов и имена. Фикстуры обезличивать.
- В логах номера счетов маскировать (`****0851`).
- Новый формат письма: сначала заметка в `kb/vcb-emails/`, затем фикстура и тест, затем парсер.
- Сначала dry-run, запись в Дзен-мани только после проверки.
